# Heia brand assets

Drop the brand photography into this folder with the exact filenames below.
The landing page (`src/app/[locale]/page.tsx`) references these paths.

## Required files

| File | What it is | Used on |
|---|---|---|
| `heia-hero.jpg` | Editorial portrait of the woman in the leather blazer holding a dropper bottle (with HEIA wordmark). The main hero shot. | Landing hero (full-bleed), OG share image |
| `heia-flatlay.jpg` | The flat-lay of the copper grooming tools on the black-and-red velvet tray (with embossed HEIA). | "Tools of the craft" section |
| `heia-barber.jpg` | The barber working on the older client in the dark wood-panelled room (with "ALL SELF-CARE SERVICES" tagline). | "For everyone" / inclusivity section |

## Recommended specs

- Format: JPG (smaller than PNG for photo content), or WebP if you have it
- Width: at least 1920px so retina displays look sharp
- Quality: 80–85 is usually the right trade-off
- Aspect ratios in the original images are fine (~16:9 for hero/barber, 16:9 for flat-lay) — the page crops responsively

## Until the files are here

The landing renders gradient placeholders with the brand colour so the
site doesn't break. Drop the files in and refresh.
